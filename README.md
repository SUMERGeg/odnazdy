# однажды.

История из твоих мгновений: уже было, происходит сейчас и ещё может быть.

Статический сайт без сборки и серверных зависимостей. Все расчёты, настройки и открытка для шеринга работают в браузере.

## Публикация

GitHub Pages: ветка `main`, папка `/ (root)`. Каждый коммит обновляет сайт автоматически.

Локальный запуск: `python -m http.server 8080`.

Основной домен после завершения переноса: https://odnazdy.ru/

Дата рождения и привычки сохраняются только на устройстве посетителя. Процент и будущие моменты основаны на выбранной продолжительности жизни, а не на персональном прогнозе.
